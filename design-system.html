Klinis Tenang

Hijau sage sebagai warna kerja, lime sebagai aksen penanda, netral hangat untuk bidang. Tenang untuk pengguna yang sedang khawatir, jelas untuk tenaga medis yang membaca cepat. Semua nilai di bawah tersedia sebagai variabel CSS di assets/css/style.css dan berganti otomatis di mode gelap (tombol bulan di kanan atas).
